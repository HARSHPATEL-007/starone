## 11. GLOSSARY

| Term | Definition |
|------|------------|
| **ROAS** | Return on Ad Spend — revenue generated per dollar spent on advertising |
| **CPA** | Cost Per Acquisition — cost to acquire one customer/conversion |
| **CPM** | Cost Per Mille — cost per 1,000 impressions |
| **CPC** | Cost Per Click — cost per individual ad click |
| **CTR** | Click-Through Rate — percentage of impressions that result in clicks |
| **IVT** | Invalid Traffic — non-human or fraudulent ad impressions/clicks |
| **DCO** | Dynamic Creative Optimization — real-time creative assembly based on user signals |
| **CAPI** | Conversions API — server-side event tracking for privacy-resilient measurement |
| **MMM** | Marketing Mix Modeling — statistical analysis of marketing impact on sales |
| **MTA** | Multi-Touch Attribution — credit assignment across multiple touchpoints |
| **DSP** | Demand-Side Platform — automated ad buying platform |
| **SSP** | Supply-Side Platform — automated ad selling platform for publishers |
| **OpenRTB** | Open Real-Time Bidding — protocol for programmatic ad auctions |
| **VAST** | Video Ad Serving Template — standard for video ad delivery |
| **VPAID** | Video Player-Ad Interface Definition — interactive video ad standard |
| **OMID** | Open Measurement Interface Definition — open viewability measurement |
| **MRAID** | Mobile Rich Media Ad Interface Definitions — mobile rich media standard |
| **Lookalike** | Audience segment similar to existing high-value customers |
| **Dayparting** | Scheduling ads to run at specific times of day for optimal performance |
| **Frequency Capping** | Limiting how many times a user sees the same ad |
| **Brand Safety** | Ensuring ads don't appear next to harmful or inappropriate content |
| **Incrementality** | True causal impact of advertising vs. what would have happened organically |
| **Viewability** | Metric measuring whether an ad was actually viewable by a human |
| **Attribution Window** | Time period during which a touchpoint can receive credit for a conversion |
| **First-Party Data** | Data collected directly from your audience/customers |
| **Second-Party Data** | Another company's first-party data shared via partnership |
| **Third-Party Data** | Data aggregated from multiple sources, often via data brokers |
| **Cookieless Targeting** | Audience targeting methods that don't rely on third-party cookies |
| **Contextual Targeting** | Placing ads based on the content of a webpage rather than user data |
| **Retargeting** | Showing ads to users who have previously interacted with your brand |
| **Prospecting** | Showing ads to new potential customers who haven't interacted with your brand |
| **CAC** | Customer Acquisition Cost — total cost to acquire a new customer |
